# KPI Telegram Bot Assistant

Project ini adalah bot Telegram khusus untuk memantau data KPI Maintenance.

## Cara Penggunaan (Lokal):
1. Ekstrak file ini.
2. Install library: `pip install -r requirements.txt`
3. Isi file `.env` dengan token dan URL database Anda.
4. Jalankan: `python main.py`

## Cara Deploy ke Railway:
1. Buat project baru di Railway.
2. Upload file project ini.
3. Masukkan Variables: `TELEGRAM_BOT_TOKEN`, `DATABASE_URL`, dan `OPENAI_API_KEY`.
